# Bruno Electric Estimating (PWA)

Private source for the Bruno Electric Services LLC estimating web app.

## iPhone install (Add to Home Screen)

1. Open the GitHub Pages HTTPS URL in **Safari** (not Chrome).
2. Tap Share → **Add to Home Screen**.
3. Open the icon — works offline after first load.

## Local open

Serve this folder over HTTPS (required for installable PWA). `index.html` alone works for desktop use in any browser.
